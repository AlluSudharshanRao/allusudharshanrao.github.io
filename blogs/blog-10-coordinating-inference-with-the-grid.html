Coordinating inference with the grid

OpenG2G compares droop, online feedback optimization (OFO), and PPO using inference batch size as the main actuator [1, §4].

Batch size as a grid actuator

Batch size changes quickly—no redeploy, no hard stop. It moves power, throughput, and inter-token latency together [7,8]. The control rule is intuitive:

  • Overvoltage → increase batch → soak more watts
  • Undervoltage → decrease batch → shed watts

The hard part is magnitude: large enough to fix voltage, small enough to protect tok/s and latency. OpenG2G also supports replica scaling; batch size is the focus because it is fast and well measured.

Three controllers, one scenario library

ControllerIdeaGrid / AI model
No coordinationFixed batch (128)Baseline
DroopLinear reaction to worst voltage violationNo explicit throughput model
OFOFitted batch→(power, throughput, latency) + grid sensitivity matrixOptimization each step [26]
PPORL policy: decrement / hold / increment batch per LLMModel-free, learns from interaction [41]

Evaluations use IEEE 13-/34-/123-bus feeders with one, two, and four datacenters, modern LLMs (Llama 3.1, Qwen 3), random generation/load profiles, optional training overlay, 3600 s episodes, 1 s control steps [1, §4].

Throughput is not free

Aggressive voltage control can shrink batches and cut tok/s. On smaller feeders PPO sometimes keeps higher throughput than OFO by tolerating more violation; OFO stays on the Pareto front across all three systems in the paper’s scatter plots [1, Fig. 3]. The “best” controller depends on how the datacenter weights watts vs tokens vs grid support—often codified in contracts with the utility.

What batch trajectories look like

Under the same disturbance, droop and OFO produce step-like batch changes around undervoltage (~1000 s) and overvoltage (~3000 s) events. OFO tends to hold larger batches when safe. PPO learns per-model policies—different LLMs adjust differently as long as reward is high [1, Fig. 4].

Link to LLM serving. Continuous batching already mixes prefill and decode. Grid coordination adds another scheduler objective: keep voltages in band while tokens still flow.
